# Методологія: Agile

Модель розробки — Agile: спрощений Scrum для одного розробника з AI-асистентом.

## Чому Agile

- три методи незалежні, тож кожен можна довести до робочого стану з тестами окремим приростом;
- вигляд графіків та анімації уточнюється лише після перегляду в браузері;
- критичне завдання (Гаусс без вибору головного елемента → збій → виправлення) природно є двома короткими приростами.

## Порівняння з іншими моделями

| Модель | Оцінка для проєкту |
| --- | --- |
| Waterfall | Пізнє тестування; зміна вигляду анімації змушує повертатися на попередні фази |
| V-модель | Сильний зв’язок вимог і тестів, але послідовність фаз жорстка |
| Спіраль | Окремий аналіз ризиків на кожному витку надлишковий для навчальної роботи |
| Agile | Короткі прирости з тестами і робочим результатом |

## Правила

- Definition of Done: `npm test` проходить, приріст зафіксовано комітом.
- Повідомлення коміту: `[AI] Спринт N: що стало робочим`. Мітки походження: `[AI]`, `[AI+edit]`, `[manual]`.
