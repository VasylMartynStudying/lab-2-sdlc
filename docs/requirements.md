# Технічне завдання

## Призначення

Програма розв’язує систему лінійних алгебраїчних рівнянь Ax = b трьома методами — Гаусса з вибором головного елемента, Якобі та Зейделя — і порівнює їх за точністю, збіжністю та швидкодією для n = 5, 10, 20.

## Дані варіанта 3

- позадіагональні елементи: aᵢⱼ = e^(−(i − j)²), i ≠ j;
- діагональні елементи: aᵢᵢ = Σⱼ≠ᵢ |aᵢⱼ| + d, d = 1 (основний розрахунок) і d = 0,1 (дослідження);
- точний розв’язок: x*ᵢ = (−1)ⁱ · i;
- права частина: b = A · x*.

Індекси i, j починаються з 1.

## Інтерфейс

Панель введення ліворуч, результати праворуч. Кольори методів незмінні на всіх графіках. Помилки вводу показуються текстом із номером рядка.

## Обмеження

- лише JavaScript без бібліотек і без збирача; сторінка відкривається як файл;
- обчислювальні модулі не залежать від DOM, щоб їх запускали тести Node.js;
- бібліотечні розв’язувачі (numpy) дозволені тільки в скрипті перевірки результатів;
- розмір системи від 1 до 50.

## Виняткові ситуації

| Ситуація | Реакція |
| --- | --- |
| Вироджена матриця | Метод Гаусса зупиняється з повідомленням, ітераційні методи не запускаються |
| Нульовий діагональний елемент | Якобі та Зейдель позначаються як незастосовні, Гаусс працює |
| Немає діагональної переваги | Попередження: збіжність не гарантована, ітерації запускаються |
| Розбіжність | Зупинка, коли значення виходять за 10¹⁰⁰ або стають нескінченними |
| Вичерпано ліміт ітерацій | Статус «не досягнуто точності» з останнім наближенням |
| Помилка у файлі | Повідомлення з номером рядка, попередні результати прибираються |
