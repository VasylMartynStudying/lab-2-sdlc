# СЛАР: прямі та ітераційні методи

Лабораторна робота № 2, варіант 3. Вебзастосунок розв’язує Ax = b методом Гаусса з вибором головного елемента, методами Якобі та Зейделя і порівнює їх за точністю, збіжністю та часом для n = 5, 10, 20.

Запуск не потребує збірки чи сервера: відкрийте `index.html` у браузері.

## Варіант 3

- aᵢⱼ = e^(−(i − j)²), i ≠ j; aᵢᵢ = Σⱼ≠ᵢ |aᵢⱼ| + d, d = 1 та 0,1;
- x*ᵢ = (−1)ⁱ · i; b = A · x*.

## Можливості

- генерація системи варіанта (n = 5, 10, 20, будь-яке d > 0), введення вручну і з файлу;
- точність ε, ліміт ітерацій 20 000 … 1 000 000;
- перевірка діагональної переваги, виявлення виродженої матриці, нульової діагоналі та розбіжності;
- таблиці: ітерації, ‖Ax − b‖₂, ‖x − x*‖₂, час; зведення для трьох розмірів;
- графіки розв’язку і збіжності (логарифмічна вісь) з автомасштабом;
- анімація методу Гаусса з підсвічуванням головного елемента та ітерацій Якобі й Зейделя;
- клавіші 1, 2, 3 перемикають n.

Початковий стан можна задати адресою: `index.html?n=20&d=0.1&tab=jacobi&frame=5` (`demo=swap|zero|singular|weak`).

## Формат файлу

```
# коментар
4 1 ; 5        n рядків: коефіцієнти і вільний член
1 3 ; 4
x*: 1 1        необов’язково: точний розв’язок
```

Роздільники — пробіл, табуляція або «;», дробова частина — крапка чи кома. Приклади — у теці `data/`.

## Перевірка

Потрібен Node.js 20 або новіший, залежностей немає.

```bash
npm test                      # модульні тести
npm run metrics               # docs/metrics.md
python3 scripts/verify.py     # звірка з numpy (після npm run metrics)
node scripts/pivot-demo.js    # Гаусс без вибору головного елемента і з ним
```
